# 0x14. C - Bit Manipulation

## Description

This project introduces bit manipulation in C programming. It covers binary numbers, bitwise operators, and techniques for accessing, setting, clearing, and comparing bits.

## Learning Objectives

* Understand binary representation of numbers
* Use bitwise operators (`&`, `|`, `^`, `~`, `<<`, `>>`)
* Manipulate individual bits
* Convert binary strings to integers
* Determine system endianness

## Files

| File                 | Description                                                        |
| -------------------- | ------------------------------------------------------------------ |
| 0-binary_to_uint.c   | Converts a binary string to an unsigned integer                    |
| 1-print_binary.c     | Prints the binary representation of a number                       |
| 2-get_bit.c          | Returns the value of a bit at a given index                        |
| 3-set_bit.c          | Sets the value of a bit to 1 at a given index                      |
| 4-clear_bit.c        | Sets the value of a bit to 0 at a given index                      |
| 5-flip_bits.c        | Returns the number of bits needed to convert one number to another |
| 100-get_endianness.c | Checks the endianness of the system                                |
| main.h               | Function prototypes and header definitions                         |

## Compilation

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o output
```
